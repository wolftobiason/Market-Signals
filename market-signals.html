How It Works
Methodology

Autocorrelation (50%)

Per-ETF rolling 60-day OLS tests whether past 1-day and 5-day returns predict the next daily return. β < 0 is mean reversion; β > 0 is momentum.

r_{t+1} = α + β·r_t + ε

Cross-Asset (30%)

Pairwise OLS across all ETF pairs. Each cell measures how much ETF A's return today predicts ETF B's return tomorrow. Significant lead-lag relationships are weighted into the combined signal.

r_{B,t+1} = α + β·r_{A,t} + ε

Intraday Slope (20%)

When an Alpha Vantage key is set, 60-min bars are fetched. The prior day's intraday price slope is regressed against next-day returns to capture overnight momentum or reversal.

r_{t+1} = α + β·slope_t + ε
